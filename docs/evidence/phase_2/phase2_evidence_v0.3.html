This content shows the conceptual framework used in Phase 2 of the ECTO project to move from the core tasks and responsibilities of a theorist identified in Phase 1 to a set of competencies / overarching learning goals.

In this framework, four components are distinguished: Skills, Knowledge, Capabilities, and Competencies. These are related but not interchangeable: the distinction makes explicit what a theorist needs to know, what specific operations they need to be able to perform, and what broader capacities support performance across contexts. These requirements are then integrated into broader theoretical competencies.

The framework also distinguishes four kinds of relationships between requirements and competencies: core requirements, conditional requirements, cross-cutting requirements, and inter-competency dependencies. These distinctions prevent every relevant requirement from being treated as universally necessary, and they reduce duplication across competencies.

A core requirement is directly necessary for the competency as such. A conditional requirement becomes necessary only when a particular form, implementation, or context of the competency is involved. A cross-cutting requirement supports several competencies without itself constituting a standalone competency. Inter-competency dependencies capture a different kind of relationship: a competency can depend on outputs or abilities supplied by another competency. Within these dependencies, a further distinction separates functionally dependent relationships, which are structurally necessary, from context-dependent ones, which only apply within specific contexts.
